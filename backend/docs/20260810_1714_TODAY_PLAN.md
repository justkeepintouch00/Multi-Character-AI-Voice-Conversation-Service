## 3. 오늘 가능하면 진행

### P1-1 인증 개발 방식 결정

Swagger에서 사용자 범위 API를 시험하려면 다음 중 하나를 선택해야 한다.

- 개발 전용 `X-User-Id` header
- JWT bearer token
- session cookie

이 결정 전에도 Pydantic schema와 repository는 구현할 수 있지만 실제 사용자 범위 endpoint 테스트는 제한된다.

### P1-2 Character CRUD 구현 준비

- 공통 오류 schema
- cursor pagination schema
- CharacterCreate/Update/Read schema
- character repository
- POST/GET/PATCH route
- PostgreSQL integration test
